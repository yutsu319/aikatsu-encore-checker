# アイカツ！アンコール 所持率チェッカー

『アイカツ！アンコール』のカードを「持っている／持っていない」でチェックして、所持率をまとめて見られるファンメイドのツールです。第1弾＋プロモーションカードの全130枚（パラレル12枚を含む）を収録しています。

**公開URL:** https://yutsu319.github.io/aikatsu-encore-checker/

## できること

- カードのイラストをタップすると、カード名・カテゴリ・入手方法・相場リンクなどの詳細。一覧ではカード名やカテゴリを出さず、イラストと「−／枚数／＋」だけでコンパクトに記録できます（上部のバーに全体の所持率が出ます）
- 弾・レアリティ・タイプ・部位・ブランド・入手方法・コーデで絞り込み、カード名や番号で検索
- 弾べつ／レアリティべつ／タイプべつ／部位べつの所持率と、コーデの揃い具合（あと何枚で1組そろうか）を表示
- **「発売前をのぞく」スイッチ**（ホームの「パラレルも数える」の下）… まだ手に入れられないカード（`GET_INFO` の発売日・配布開始日が今日より後）を、**カード一覧にはそのまま残したまま、所持率の計算（分母）からだけ外せます**。初期設定はON（＝入手できるようになってから所持率に数える）。発売日を迎えると自動で分母に戻ります（2026-11-21時点ではアイカツフォン等の特典9枚＋パフュームハンドの1枚＝10枚が対象、たまごっちのEP-042は発売日当日なので発売中扱い）。ヘッダーの所持数・ホームの区分／レアリティ／タイプ／部位べつの率・画像書き出しの所持率すべてに反映され、設定は `localStorage` の `hideUpcoming` に保存されます
- きょうの目標（未所持からランダムにピックアップ）
- データは端末のブラウザ（localStorage）に自動保存。JSON・共有コード（`AEC1…`）で書き出し／読み込みができるので、別の端末やお友だちとデータを渡せます
- 「📷 所持一覧を画像で保存」は、**保存前に「出すカード（所持のみ／未所持のみ／全カード）」と「所持枚数を表示するか」を選ぶ確認画面**が出ます。画像は**横1200pxの縦長1枚**（高さはカードの枚数に合わせて伸びる）で、**カードは10列・カード名なし**。上部に所持率（％）・パラレル表記・「第1弾」などのグループ見出しが入り、所持カードはゴールド枠＋枚数バッジ（「×2」、枚数を表示しない設定なら「✓」）、未所持カードは白っぽくかすんで表示されます。アクセサリーなど横長のカードは、縦の枠にぴったり収まるよう90度回して並びます。画像は長押しで写真アプリへ、「共有」でLINEなどにも送れます
- 第2弾や新しいプロモは「データ」タブの「カードを追加」にカード情報を貼り付けて取り込めます
- **🏪 遊べるお店・公式X**（ホーム）… 47都道府県と市区町村から選んで、公式サイトの取扱店舗リストをその範囲で絞った状態で開けます（未選択なら全国）。さらに、全国47都道府県の公式取扱店舗をこの画面のままキーワード検索でき、「＋ メモに追加」で「📝 よく行くお店のXメモ」（自分だけのメモ）に保存できます。公式X（[@aikatsu_dcd](https://x.com/aikatsu_dcd)）へのボタンつき

### 2026-11-18 追加（第3弾アップデート）

- **👗 コーデ > ✨ 手持ちで組めるおすすめコーデ** … いま持っているカード（`cnt > 0`）だけで全身そろうコーデを自動で抽出し、**合計AP（アピールポイント）の高い順**に表示。ホームの「コーデの揃い具合」からもワンタップで入れます。パラレル（PR★／ER★）は同じ部位の別デザインとして、どちらか1枚あればその部位はOKとして数えます。上下ワンピ＋シューズ、フルコーデ1枚のような組み方にも対応（いちばん良い組み方を自動で採用）。絞り込みは「**組める**」「**🎯 高AP 3,000〜**（PR4点・ERフルコーデがここに入る＝ハナ解放のスコア40,000以上を狙うときの第一候補）」「**あと1枚**（リーチ。足りないカードのメルカリ検索つき）」。
- **🎮 プレイ回数＆金額メモ**（🎀 イベントタブ／ホームの「今日のプレイ」から）… 1プレイ＝100円で「＋1回（100円）」「＋5回（500円）」、金額だけの「＋100円」、まちがい修正用の「−1回（100円）」「−100円」、まとめ買い用の手入力（回数・金額）で記録。**日付ピッカー**で今日以外（過去の日）も選んで記録でき、今日以外を選んでいるあいだは「◯◯ を編集中」ラベルと「今日に戻す」ボタンが出ます（初期値は今日なので、ふだんのワンタップ記録はそのまま）。**今日・今月・累計**の回数と金額をひと目で確認でき（過去日も別月なら累計、同じ月なら今月に入ります）、「さいきんの記録」は最新7日＋「もっと見る（全◯日）」で全件を確認、日ごとに削除できます。端末内（localStorage）に保存し、専用のJSON書き出し／読み込みのほか、所持データのJSONバックアップにも `play` として一緒に入ります。

「ハナ解放＝アイカツ！オールスターモード『HAPPY∞アイカツ！』のアンコールライブ成功＋スコア40,000以上」は公式の登場アイドルページ（https://dcd.aikatsu.com/encore/idol/ ・2026-11-18 確認）の記載どおりです。APはコーデの部位ごとのアピールポイント合計で、実際のスコアはプレイ内容でも変わります。

- **アンコールステージ初回クリア** … 3ステージ×3難易度の計9マスをチェックでき、各マスにもらえるパーツ／アイドルプレート名を表示。ステージごとの 0/3 と全体の 0/9 がバーで見えます（例：AIKATSU！×AIKATSU！＝★マリンブルー、★★★あみこみポニーテール、★★★★★芸能人はカードが命）。
- **新登場アイドルとアイカツ！**（2026-11-12〜１弾稼働終了まで）… 「さいごまでクリアした」の1つチェックと、メエ・パリン・たいむの解放チェックへの導線。
- スタンプ3種（１弾アイカツ！スタンプ＝10/8〜、ハロウィンアイカツ！スタンプ＝10/24〜、みならいアイドルおうえん！＝11/12〜）は、開催期間の早い順に並べたままの10マス×3です。
- 進捗は `localStorage`（`aikatsu-encore-checker.progress.v1` の `event`）に保存し、💾 データタブのJSON書き出し・読み込みにも `progress.event` として入ります（以前のスタンプ進捗・アイドル／楽曲の記録はそのまま引き継がれます）。ニュースタブのイベント詳細からは「🎀 イベントタブでチェックする ›」でそのイベントへ飛べます。

### 2026-11-21 追加（発売前のカードを所持率から除外）

- **「発売前をのぞく」スイッチ** … ホームの「パラレルも数える」のすぐ下に追加しました。ONのとき、**まだ発売前・配布前で持っていないカード**（`getInfoFor()` の `from` が今日より後）は分母から外して所持率を出します。カード一覧・コーデ一覧・詳細の「入手先・発売日メモ」には今までどおり全部並ぶので、入手方法や発売日を見落としません。ONのあいだはヘッダーに「※発売前のN種は所持率から除外中」、ホームに「まだ買えないN種は分母から外しています。発売日になると自動で戻ります。」と出ます。発売日（`from`）を過ぎると自動で分母に戻るので、日付を直す必要はありません。初期値はON（＝その日から手に入るものだけで所持率を測る）。スイッチをOFFにすると今までどおり130枚ぜんぶで計算します。

| `thumbs/` | 画像書き出し用のカードサムネイル（`{カード番号}.jpg`・幅240px・130枚で約3.5MB）。同じオリジンから読み込んでCanvasに描くため、CORSで失敗しません |

- **🎨 着せ替え（テーマ）** … ヘッダー右上の 🎨 か「💾 データ」タブのピッカーから、**6種類**の見た目をワンタップで切り替え（🌸 シンプル＝初期値／🎀 エンジェリーシュガー風／💎 フューチャリングガール風／🖤 ロリゴシック風／🦋 スパイシーアゲハ風／🌙 ラブムーンライズ風）。色・背景・ボタン・カードの質感がまとめて変わり、選択は端末の `localStorage`（`aikatsu-encore-checker.theme.v1`）に保存されます。公式ロゴや画像は使わず、CSSグラデーションとSVGのリボン・羽・ハート・星・三日月などの装飾だけで雰囲気をつくっています。5つのブランドテーマは、それぞれの代表プレミアムドレスの世界観に寄せて作り込んでいます。🎀 は白×パステルピンクに淡いオーロラの虹色シアー、ふんわり舞う白い羽根と大きなサテンリボン、カード上端のリボン飾りと2段フリル／スカラップレースの裾。💎 は深い宇宙ネイビーに天の川の帯と星座の光ライン、半透明ガラスのカードにネオンシアンの発光ボーダーと四隅の星・プリズム飾り。🖤 は漆黒×ワインレッドに白いフリル襟と銀のチェーン・十字架、黒レースの裾とダマスクの透かし。🦋 は漆黒×ショッキングピンク×ゴールドに大輪の薔薇と舞うアゲハ蝶、金ラメのビジューライン。🌙 はロイヤルパープル×深紅×シャンパンゴールドに、ゴールドのティアラ、大きな三日月と瞬く星屑、オーロラの夜空。ダーク系テーマでも文字・数字・入力欄・カレンダーは高コントラストで読めるよう配色しています。

保存キー（localStorage）: `aikatsu-encore-checker.v1`（所持数）/ `aikatsu-encore-checker.progress.v1`（アイドル・楽曲・スタンプ・イベントの進捗）/ `aikatsu-encore-checker.myshot.v1`（マイショット）/ `aikatsu-encore-checker.play.v1`（プレイ回数＆金額メモ）/ `aikatsu-encore-checker.theme.v1`（着せ替えテーマ）/ `aikatsu-encore-checker.shops.v1`（選んだ都道府県・市区町村とお店のXメモ）。所持データの共有コード `AEC1…` とJSON書き出しは従来のまま使えます（JSONには第3弾のプレイメモも `play` として、お店のXメモも `shops` として入ります）。
