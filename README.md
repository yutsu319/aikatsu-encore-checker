# アイカツ！アンコール 所持率チェッカー

『アイカツ！アンコール』のカードを「持っている／持っていない」でチェックして、所持率をまとめて見られるファンメイドのツールです。第1弾＋プロモーションカードの全130枚（パラレル12枚を含む）を収録しています。

**公開URL:** https://yutsu319.github.io/aikatsu-encore-checker/

## できること

- カードのイラストをタップすると、カード名・カテゴリ・入手方法・相場リンクなどの詳細。一覧ではカード名やカテゴリを出さず、イラストと「−／枚数／＋」だけでコンパクトに記録できます（上部のバーに全体の所持率が出ます）
- 弾・レアリティ・タイプ・部位・ブランド・入手方法・コーデで絞り込み、カード名や番号で検索
- 弾べつ／レアリティべつ／タイプべつ／部位べつの所持率と、コーデの揃い具合（あと何枚で1組そろうか）を表示
- きょうの目標（未所持からランダムにピックアップ）
- データは端末のブラウザ（localStorage）に自動保存。JSON・共有コード（`AEC1…`）で書き出し／読み込みができるので、別の端末やお友だちとデータを渡せます
- 「📷 所持一覧を画像で保存」は、**保存前に「出すカード（所持のみ／未所持のみ／全カード）」と「所持枚数を表示するか」を選ぶ確認画面**が出ます。画像は**横1200pxの縦長1枚**（高さはカードの枚数に合わせて伸びる）で、**カードは10列・カード名なし**。上部に所持率（％）・パラレル表記・「第1弾」などのグループ見出しが入り、所持カードはゴールド枠＋枚数バッジ（「×2」、枚数を表示しない設定なら「✓」）、未所持カードは白っぽくかすんで表示されます。アクセサリーなど横長のカードは、縦の枠にぴったり収まるよう90度回して並びます。画像は長押しで写真アプリへ、「共有」でLINEなどにも送れます
- 第2弾や新しいプロモは「データ」タブの「カードを追加」にカード情報を貼り付けて取り込めます
- **🏪 遊べるお店・公式X**（ホーム）… 47都道府県と市区町村から選んで、公式サイトの取扱店舗リストをその範囲で絞った状態で開けます（未選択なら全国）。さらに、全国47都道府県の公式取扱店舗をこの画面のままキーワード検索でき、「＋ メモに追加」で「📝 よく行くお店のXメモ」（自分だけのメモ）に保存できます。公式X（[@aikatsu_dcd](https://x.com/aikatsu_dcd)）へのボタンつき

### 2026-11-18 追加（第2弾アップデート）

- **🎤 アイドル**タブ … 登場アイドル全11人の解放チェック（メエ・パリン・たいむは「きかんげんていライブ」の指定3曲ごとのチェック付き／3曲そろうと自動で解放済み）、全11曲の「遊べるモード・あそべるアイドル・どの曲で誰が解放されるか」とプレイ済み／アンコール成功の記録、1弾で開催中のアイカツ！スタンプ3種（各10マス・報酬つき）の進捗
- **📰 ニュース**タブ … 公式ニュースの発売日・配布期間・終了日を「あと何日」つきで一覧表示（2026-11-20 ボーナスキャンペーン、11-21 たまごっちコラボ、11-28 アイカツフォン／おうえんスターライト、12-10 一番くじちょこっと、2027-01-18 パフュームハンド、2027-02末 ドレスアップコレクションなど）。日付を過ぎると自動で「終了」に変わります
- **📅 ニュース > カレンダー** … 月間カレンダー（`◀ 2026年11月 ▶`、今月に戻るボタン）で、`SCHEDULE` 配列の `start` / `end` から**期間バーと矢印**を自動生成。開始日〜終了日（`end` 未定の期間ものは「１弾稼働終了まで」など）の予定は、週をまたいで横に伸びるカラーバー（開始日に丸角・継続端に `▶`、ラベル名入り／続きの週は細いひも状バー）で表示し、単日の発売・配布日は日付マスの丸い点（カテゴリ色）で表示します。帯の色はゲーム／カード／グッズ／キャンペーンの4色。日付か帯をタップすると下に「その日の予定」カードが出て、「リストで見る」でリストの該当ニュースへ移動します。ニュースを `SCHEDULE` に足せばカレンダーにも自動で反映されます
- **📸 マイショット**タブ … 自分専用のプレイ日記。写真は端末内（localStorage）だけに保存され、選ぶと Canvas で長辺720px・JPEG品質0.72に自動で軽量化。日付・遊んだ曲やコーデ・ひとことメモを添えて保存／タップで拡大／削除／JSONバックアップができます（使用量の目安つき）

アイドル・楽曲・スタンプ・ニュースの内容は公式サイト（[登場アイドル](https://dcd.aikatsu.com/encore/idol/)・[楽曲リストPDF](https://dcd.aikatsu.com/encore/pdf/music-list.pdf)・[ニュース](https://dcd.aikatsu.com/encore/news/004.php)）を 2026-11-18 に確認して作成しています。ニュースは `index.html` 内の `SCHEDULE` 配列に1件足すだけで表示・並び・「あと何日」が自動更新されます。

### 2026-11-18 追加（第3弾アップデート）

- **👗 コーデ > ✨ 手持ちで組めるおすすめコーデ** … いま持っているカード（`cnt > 0`）だけで全身そろうコーデを自動で抽出し、**合計AP（アピールポイント）の高い順**に表示。ホームの「コーデの揃い具合」からもワンタップで入れます。パラレル（PR★／ER★）は同じ部位の別デザインとして、どちらか1枚あればその部位はOKとして数えます。上下ワンピ＋シューズ、フルコーデ1枚のような組み方にも対応（いちばん良い組み方を自動で採用）。絞り込みは「**組める**」「**🎯 高AP 3,000〜**（PR4点・ERフルコーデがここに入る＝ハナ解放のスコア40,000以上を狙うときの第一候補）」「**あと1枚**（リーチ。足りないカードのメルカリ検索つき）」。
- **🎮 プレイ回数＆金額メモ**（🎤 アイドルタブのスタンプの下／ホームの「今日のプレイ」から）… 1プレイ＝100円で「＋1回（100円）」「＋5回（500円）」、金額だけの「＋100円」、まちがい修正用の「−1回（100円）」「−100円」、まとめ買い用の手入力（回数・金額）で記録。**日付ピッカー**で今日以外（過去の日）も選んで記録でき、今日以外を選んでいるあいだは「◯◯ を編集中」ラベルと「今日に戻す」ボタンが出ます（初期値は今日なので、ふだんのワンタップ記録はそのまま）。**今日・今月・累計**の回数と金額をひと目で確認でき（過去日も別月なら累計、同じ月なら今月に入ります）、「さいきんの記録」は最新7日＋「もっと見る（全◯日）」で全件を確認、日ごとに削除できます。端末内（localStorage）に保存し、専用のJSON書き出し／読み込みのほか、所持データのJSONバックアップにも `play` として一緒に入ります。

「ハナ解放＝アイカツ！オールスターモード『HAPPY∞アイカツ！』のアンコールライブ成功＋スコア40,000以上」は公式の登場アイドルページ（https://dcd.aikatsu.com/encore/idol/ ・2026-11-18 確認）の記載どおりです。APはコーデの部位ごとのアピールポイント合計で、実際のスコアはプレイ内容でも変わります。

### 2026-11-19 追加（第4弾アップデート）

- **🏷️ カード詳細の「入手先・発売日メモ」** … カードの詳細モーダルに**入手先（配布場所）／対象商品・条件／定価目安／発売日・配布期間**を表で表示。`GET_INFO`（入手方法ごと）と `GET_INFO_CARD`（キャンペーンの何弾配布か）で持ち、**今日の日付から「配布中／配布前／配布終了／発売前／発売中」バッジを自動判定**します。第1弾・パラレルは「第1弾 筐体から排出（1プレイ100円〜）」、プロモははじめようプレゼントキャンペーンの第1〜4弾の配布開始日、アイカツフォン（13,200円）／おうえんスターライト（各1,925円）／パフュームハンド（1,430円）の税込価格と発売日、オフィシャルストアの「1会計税込2,000円ごとに1枚」、しまむらの「オンライン（しまむらパーク）はカード付きなし」、セブン-イレブンのグリコ菓子3個キャンペーン（10/8〜10/21＝**配布終了**）、ちゃお2026年11月号（790円）などを、公式サイト（news/001・003・006・007・010、ストアのお知らせ）で2026-11-19に確認した内容だけ記載。未確認の価格・日付は書かず、各メモに公式の表記と出典リンクを付けています。

### 2026-11-19 追加（お店さがし）

- **🏪 遊べるお店・公式X**（ホーム、所持一覧の画像ボタンの下）… **都道府県**（未選択＝全国）と**市区町村**（都道府県を選ぶと選べる）のセレクトから、下のボタンが公式サイトの取扱店舗リストを**その範囲で絞った状態**で開きます。URLは `https://dcd.aikatsu.com/encore/shoplist/list.php?pref=XX`（市区町村まで選ぶと `&city=...`）で、2026-11-19 に実URLで絞り込み結果を確認済み。未選択のときは店舗検索のトップ（`https://dcd.aikatsu.com/encore/shoplist/`）を開きます。選択は端末の `localStorage` にだけ保存され、初期値は未選択です。同じパネルに**公式X（@aikatsu_dcd）**へのボタンと、公式の注意書き（稼働台数・排出弾は更新時点の目安／店舗への直接のお問い合わせは控えるよう案内）を表示しています。
- **🔍 公式の取扱店舗をさがす** … 全国47都道府県ぶんの公式取扱店舗（**2026-11-19 取得・927店舗**）を、チェッカーの中のままキーワード（店名・市区町村・住所）でさがせます。都道府県・市区町村のセレクトと連動し、**何も選ばずキーワードも2文字未満のときは一覧を出さず案内だけ**を表示（スマホで縦に伸びすぎないよう10件ずつ＋「もっと見る」）。各候補に店名・住所・**公式リンク**（その市区町村の公式ページ）と「**＋ メモに追加**」ボタン（追加済みなら「追加済み」）。データは `shops-data.js` に公式サイトの公開情報（店名・都道府県・市区町村・住所）として同梱し、**検索をはじめたときにだけ読み込み**ます（取得日は「公式データ：2026-11-19 取得」と表示）。
- **📝 よく行くお店のXメモ** … 公式検索から追加したお店と、手入力で足したお店をまとめて管理（**20件まで**、5店舗前後の普段使い想定）。各メモは店名・住所（公式から追加した場合）・公式店舗検索リンク・**X紐づけ**（`@アカウント名` か検索語をその場で書きかえて「保存」）・**「Xをひらく」**（`@〜` は `https://x.com/{handle}`、ことばか未設定は店名で `https://x.com/search?q=…&f=live`）・削除（×）を持ちます。**文字はすべてこの端末の `localStorage`（`aikatsu-encore-checker.shops.v1`）にだけ保存し、サーバーへ送信しません**。形式は従来の `shops.v1`（`pref` ＋ `list[{name,q}]`）のままで、新しい項目には `pref` / `city` / `addr` が増えるだけ（古いJSONもそのまま読めます）。JSON書き出しの `shops` に `city` も入り、読み込み時は既存のメモを消さずに不足分だけ追加します（同じ名前と住所のものは重複しない。共有コード `AEC1…` は所持枚数だけなので含まれません）。

店舗情報は公式サイト（[取扱店舗](https://dcd.aikatsu.com/encore/shoplist/)）と公式X（[@aikatsu_dcd](https://x.com/aikatsu_dcd)）だけで確認できるようにしています。**コード・HTML・READMEに特定の店舗名や市区町村名は書かず**、店舗名・住所・市区町村名は公開情報として取得した `shops-data.js` と、使う人が自分で選ぶ都道府県リストだけに置いています（検索欄の例も「店名・市区町村・住所で検索」のように汎用、初期選択は未選択）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体。カードデータを内部に埋め込み済みで、これ1枚で動きます（カード画像は公式サイトの画像を読み込み） |
| `cards.json` | カードマスタ（`meta` + `cards` 配列／130枚）。第2弾・プロモ追加時のメンテナンス用 |
| `shops-data.js` | 公式サイト「取扱店舗」の公開情報（店名・都道府県・市区町村・住所／2026-11-19 取得・927店舗）。チェッカーの店舗検索で、さがしはじめたときにだけ読み込みます |
| `thumbs/` | 画像書き出し用のカードサムネイル（`{カード番号}.jpg`・幅240px・130枚で約3.5MB）。同じオリジンから読み込んでCanvasに描くため、CORSで失敗しません |

- **🎨 着せ替え（テーマ）** … ヘッダー右上の 🎨 か「💾 データ」タブのピッカーから、**6種類**の見た目をワンタップで切り替え（🌸 シンプル＝初期値／🎀 エンジェリーシュガー風／💎 フューチャリングガール風／🖤 ロリゴシック風／🦋 スパイシーアゲハ風／🌙 ラブムーンライズ風）。色・背景・ボタン・カードの質感がまとめて変わり、選択は端末の `localStorage`（`aikatsu-encore-checker.theme.v1`）に保存されます。公式ロゴや画像は使わず、CSSグラデーションとSVGのリボン・羽・ハート・星・三日月などの装飾だけで雰囲気をつくっています。5つのブランドテーマは、それぞれの代表プレミアムドレスの世界観に寄せて作り込んでいます。🎀 は白×パステルピンクに淡いオーロラの虹色シアー、ふんわり舞う白い羽根と大きなサテンリボン、カード上端のリボン飾りと2段フリル／スカラップレースの裾。💎 は深い宇宙ネイビーに天の川の帯と星座の光ライン、半透明ガラスのカードにネオンシアンの発光ボーダーと四隅の星・プリズム飾り。🖤 は漆黒×ワインレッドに白いフリル襟と銀のチェーン・十字架、黒レースの裾とダマスクの透かし。🦋 は漆黒×ショッキングピンク×ゴールドに大輪の薔薇と舞うアゲハ蝶、金ラメのビジューライン。🌙 はロイヤルパープル×深紅×シャンパンゴールドに、ゴールドのティアラ、大きな三日月と瞬く星屑、オーロラの夜空。ダーク系テーマでも文字・数字・入力欄・カレンダーは高コントラストで読めるよう配色しています。

保存キー（localStorage）: `aikatsu-encore-checker.v1`（所持数）/ `aikatsu-encore-checker.progress.v1`（アイドル・楽曲・スタンプ）/ `aikatsu-encore-checker.myshot.v1`（マイショット）/ `aikatsu-encore-checker.play.v1`（プレイ回数＆金額メモ）/ `aikatsu-encore-checker.theme.v1`（着せ替えテーマ）/ `aikatsu-encore-checker.shops.v1`（選んだ都道府県・市区町村とお店のXメモ）。所持データの共有コード `AEC1…` とJSON書き出しは従来のまま使えます（JSONには第3弾のプレイメモも `play` として、お店のXメモも `shops` として入ります）。
