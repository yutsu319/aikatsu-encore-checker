# アイカツ！アンコール 所持率チェッカー

『アイカツ！アンコール』のカードを「持っている／持っていない」でチェックして、所持率をまとめて見られるファンメイドのツールです。第1弾＋プロモーションカードの全130枚（パラレル12枚を含む）を収録しています。

**公開URL:** https://yutsu319.github.io/aikatsu-encore-checker/

## できること

- カードのイラストをタップすると、カード名・カテゴリ・入手方法・相場リンクなどの詳細。一覧ではカード名やカテゴリを出さず、イラストと「−／枚数／＋」だけでコンパクトに記録できます（上部のバーに全体の所持率が出ます）
- 弾・レアリティ・タイプ・部位・ブランド・入手方法・コーデで絞り込み、カード名や番号で検索
- 弾べつ／レアリティべつ／タイプべつ／部位べつの所持率と、コーデの揃い具合（あと何枚で1組そろうか）を表示
- きょうの目標（未所持からランダムにピックアップ）
- データは端末のブラウザ（localStorage）に自動保存。JSON・共有コード（`AEC1…`）で書き出し／読み込みができるので、別の端末やお友だちとデータを渡せます
- 「📷 所持一覧を画像で保存」は、**保存前に「出すカード（所持のみ／未所持のみ／全カード）」と「所持枚数を表示するか」を選ぶ確認画面**が出ます。画像は**横1200pxの縦長1枚**（高さはカードの枚数に合わせて伸びる）で、**カードは10列・カード名なし**。上部に所持率（％）・パラレル表記・「第1弾」などのグループ見出しが入り、所持カードはゴールド枠＋枚数バッジ（「×2」、枚数を表示しない設定なら「✓」）、未所持カードは白っぽくかすんで表示されます。アクセサリーなど横長のカードは、縦の枠にぴったり収まるよう90度回して並びます。画像は長押しで写真アプリへ、「共有」でLINEなどにも送れます
- 第2弾や新しいプロモは「データ」タブの「カードを追加」にカード情報を貼り付けて取り込めます

### 2026-11-18 追加（第2弾アップデート）

- **🎤 アイドル**タブ … 登場アイドル全11人の解放チェック（メエ・パリン・たいむは「きかんげんていライブ」の指定3曲ごとのチェック付き／3曲そろうと自動で解放済み）、全11曲の「遊べるモード・あそべるアイドル・どの曲で誰が解放されるか」とプレイ済み／アンコール成功の記録、1弾で開催中のアイカツ！スタンプ3種（各10マス・報酬つき）の進捗
- **📰 ニュース**タブ … 公式ニュースの発売日・配布期間・終了日を「あと何日」つきで一覧表示（2026-11-20 ボーナスキャンペーン、11-21 たまごっちコラボ、11-28 アイカツフォン／おうえんスターライト、12-10 一番くじちょこっと、2027-01-18 パフュームハンド、2027-02末 ドレスアップコレクションなど）。日付を過ぎると自動で「終了」に変わります
- **📅 ニュース > カレンダー** … 月間カレンダー（`◀ 2026年11月 ▶`、今月に戻るボタン）で、`SCHEDULE` 配列の `start` / `end` から**期間バーと矢印**を自動生成。開始日〜終了日（`end` 未定の期間ものは「１弾稼働終了まで」など）の予定は、週をまたいで横に伸びるカラーバー（開始日に丸角・継続端に `▶`、ラベル名入り／続きの週は細いひも状バー）で表示し、単日の発売・配布日は日付マスの丸い点（カテゴリ色）で表示します。帯の色はゲーム／カード／グッズ／キャンペーンの4色。日付か帯をタップすると下に「その日の予定」カードが出て、「リストで見る」でリストの該当ニュースへ移動します。ニュースを `SCHEDULE` に足せばカレンダーにも自動で反映されます
- **📸 マイショット**タブ … 自分専用のプレイ日記。写真は端末内（localStorage）だけに保存され、選ぶと Canvas で長辺720px・JPEG品質0.72に自動で軽量化。日付・遊んだ曲やコーデ・ひとことメモを添えて保存／タップで拡大／削除／JSONバックアップができます（使用量の目安つき）

アイドル・楽曲・スタンプ・ニュースの内容は公式サイト（[登場アイドル](https://dcd.aikatsu.com/encore/idol/)・[楽曲リストPDF](https://dcd.aikatsu.com/encore/pdf/music-list.pdf)・[ニュース](https://dcd.aikatsu.com/encore/news/004.php)）を 2026-11-18 に確認して作成しています。ニュースは `index.html` 内の `SCHEDULE` 配列に1件足すだけで表示・並び・「あと何日」が自動更新されます。

### 2026-11-18 追加（第3弾アップデート）

- **👗 コーデ > ✨ 手持ちで組めるおすすめコーデ** … いま持っているカード（`cnt > 0`）だけで全身そろうコーデを自動で抽出し、**合計AP（アピールポイント）の高い順**に表示。ホームの「コーデの揃い具合」からもワンタップで入れます。パラレル（PR★／ER★）は同じ部位の別デザインとして、どちらか1枚あればその部位はOKとして数えます。上下ワンピ＋シューズ、フルコーデ1枚のような組み方にも対応（いちばん良い組み方を自動で採用）。絞り込みは「**組める**」「**🎯 高AP 3,000〜**（PR4点・ERフルコーデがここに入る＝ハナ解放のスコア40,000以上を狙うときの第一候補）」「**あと1枚**（リーチ。足りないカードのメルカリ検索つき）」。
- **🎮 プレイ回数＆金額メモ**（🎤 アイドルタブのスタンプの下／ホームの「今日のプレイ」から）… 1プレイ＝100円で「＋1回（100円）」「＋5回（500円）」、金額だけの「＋100円」、まちがい修正用の「−1回（100円）」「−100円」、まとめ買い用の手入力（回数・金額）で記録。**日付ピッカー**で今日以外（過去の日）も選んで記録でき、今日以外を選んでいるあいだは「◯◯ を編集中」ラベルと「今日に戻す」ボタンが出ます（初期値は今日なので、ふだんのワンタップ記録はそのまま）。**今日・今月・累計**の回数と金額をひと目で確認でき（過去日も別月なら累計、同じ月なら今月に入ります）、「さいきんの記録」は最新7日＋「もっと見る（全◯日）」で全件を確認、日ごとに削除できます。端末内（localStorage）に保存し、専用のJSON書き出し／読み込みのほか、所持データのJSONバックアップにも `play` として一緒に入ります。

「ハナ解放＝アイカツ！オールスターモード『HAPPY∞アイカツ！』のアンコールライブ成功＋スコア40,000以上」は公式の登場アイドルページ（https://dcd.aikatsu.com/encore/idol/ ・2026-11-18 確認）の記載どおりです。APはコーデの部位ごとのアピールポイント合計で、実際のスコアはプレイ内容でも変わります。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体。カードデータを内部に埋め込み済みで、これ1枚で動きます（カード画像は公式サイトの画像を読み込み） |
| `cards.json` | カードマスタ（`meta` + `cards` 配列／130枚）。第2弾・プロモ追加時のメンテナンス用 |
| `thumbs/` | 画像書き出し用のカードサムネイル（`{カード番号}.jpg`・幅240px・130枚で約3.5MB）。同じオリジンから読み込んでCanvasに描くため、CORSで失敗しません |

- **🎨 着せ替え（テーマ）** … ヘッダー右上の 🎨 か「💾 データ」タブのピッカーから、**6種類**の見た目をワンタップで切り替え（🌸 シンプル＝初期値／🎀 エンジェリーシュガー風／💎 フューチャリングガール風／🖤 ロリゴシック風／🦋 スパイシーアゲハ風／🌙 ラブムーンライズ風）。色・背景・ボタン・カードの質感がまとめて変わり、選択は端末の `localStorage`（`aikatsu-encore-checker.theme.v1`）に保存されます。公式ロゴや画像は使わず、CSSグラデーションとSVGのリボン・羽・ハート・星・三日月などの装飾だけで雰囲気をつくっています。各テーマはブランドのモチーフに寄せて飾りを重ねていて、🎀 は立体的なリボンとスカラップレース、💎 はネオンシアンの格子と四隅のコーナーブラケット、🖤 は黒×ワインレッドの額縁とゴシックレース・ダマスク、🦋 は舞うアゲハ蝶とゴールドのレース、🌙 は夜空のオーロラとシャンパンゴールドのアーチで彩ります（どのテーマも文字と数字の読みやすさは保っています）。

保存キー（localStorage）: `aikatsu-encore-checker.v1`（所持数）/ `aikatsu-encore-checker.progress.v1`（アイドル・楽曲・スタンプ）/ `aikatsu-encore-checker.myshot.v1`（マイショット）/ `aikatsu-encore-checker.play.v1`（プレイ回数＆金額メモ）/ `aikatsu-encore-checker.theme.v1`（着せ替えテーマ）。所持データの共有コード `AEC1…` とJSON書き出しは従来のまま使えます（JSONには第3弾のプレイメモも `play` として入ります）。

## 収録データ

| 区分 | 枚数 |
|---|---|
| 第1弾 通常（E1-01〜E1-85） | 85 |
| 第1弾 パラレル（PR★ 8／ER★ 4） | 12 |
| プロモ | 33 |
| 合計 | 130 |

- 枚数・レアリティ・カード番号は公式カードリスト（https://dcd.aikatsu.com/encore/cardlist/ ）に準拠
- カード名・部位・タイプ・ブランド・AP・コーデ・カード裏面の説明文はカード研究所（https://card-search.com/aikatsu-encore/cards ）を参照して作成
- アプリ内のカード画像は公式サイトの画像URLを直接参照しています（`thumbs/` は画像書き出し用のサムネイル）
